# 1101
12306 余票查询小助手

一个用 Python 写的命令行小工具：输入出发日期、出发站和到达站，就能列出当天所有车次的余票信息，不用再打开网页逐趟翻。

功能

- 支持全国任意两个火车站之间查询
- 一次列出所有车次：车次号、发到站、发到时间、历时
- 显示各席别余票：商务座、一等座、二等座、软卧、硬卧、硬座、无座等
- 车站代码表自动下载并本地缓存，第二次运行更快

运行环境

- Python 3.8 及以上
- 依赖库：`requests`

安装

```bash
pip install -r requirements.txt
```

使用方法

方式一：命令行直接带参数

```bash
python query_tickets.py 2026-11-28 北京 上海
```

方式二：不带参数运行，按提示输入

```bash
python query_tickets.py
```

```
出发日期（格式 YYYY-MM-DD，回车默认明天）: 
出发站（如 北京）: 广州
到达站（如 上海）: 深圳
```

运行效果

```
正在查询 2026-11-28  北京 → 上海 的余票……

车次     出发站   到达站   出发     到达     历时     商务座/特等座  一等座  二等座  ……
--------------------------------------------------------------------------------
G1     北京南   上海虹桥  06:30  11:24  04:54  无        有    有
G5     北京    上海    07:40  12:32  04:52  无        13   有
……
```

数字表示余票张数，`有` 表示余票充足，`-` 表示无此席别或无票。

项目结构

```
├── query_tickets.py   # 主程序（查询逻辑 + 表格展示）
├── requirements.txt   # 依赖清单
└── stations.json      # 车站代码缓存（首次运行自动生成）
```

实现思路

1. 从 12306 的 `station_name.js` 解析出「车站中文名 → 三字代码」映射，缓存到本地；
2. 带上 Cookie 调用 12306 余票查询接口 `leftTicket/queryG`；
3. 按接口固定的字段下标解析每趟车的席别余票，排版成表格输出。

声明

本项目仅供学习 Python 网络请求与数据处理使用，数据来自 12306 官方公开查询接口，查询结果以 12306 官网为准。请勿用于任何商业或违规用途。
